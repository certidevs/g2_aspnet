# Guía de IDE

Usamos Visual Studio Code con C# Dev Kit como entorno del curso. También se puede abrir la solución con un IDE compatible con .NET 10.

1. Instalar el SDK de .NET 10 y Git.
2. Instalar Visual Studio Code y C# Dev Kit.
3. Abrir la carpeta `g2_aspnet`, donde está `G2AspNet.sln`.
4. Restaurar las dependencias y las herramientas locales.
5. Ejecutar el perfil `http` o preparar la depuración según la configuración del editor.

La [guía del repositorio](https://github.com/certidevs/g2_aspnet/blob/main/docs/IDE-SETUP.md) contiene las instrucciones del entorno. Los comandos para arrancar y los puertos están en [Primeros pasos](https://github.com/certidevs/g2_aspnet/wiki/Primeros-pasos).
