# Presentación del proyecto

## Qué estamos construyendo

Nuestro proyecto es una aplicación web para gestionar academias y centros de formación. Reunimos centros, cursos, aulas, lecciones, matrículas, notas y asistencias en una misma aplicación.

## Cómo lo hemos organizado

Usamos C#, ASP.NET Core MVC y Razor para la aplicación web, Entity Framework Core con SQLite para los datos e Identity para las cuentas. Trabajamos en equipo con Git y GitHub.

## Qué podemos enseñar

Podemos recorrer los centros y cursos, consultar las aulas y lecciones, acceder con las cuentas de alumno y profesor y mostrar la administración de usuarios. El [guion de demostración](https://github.com/certidevs/g2_aspnet/wiki/Demostracion) recoge el recorrido.

## Qué nos falta

Tenemos pendientes las operaciones de escritura de aulas y lecciones, completar permisos, ampliar las pruebas y sustituir el borrado de la base por una solución que conserve los datos.

## Guion breve

1. Explicar el problema que resolvemos.
2. Enseñar el [modelo de datos](https://github.com/certidevs/g2_aspnet/wiki/Modelo-de-datos).
3. Hacer la demostración con los perfiles disponibles.
4. Explicar la [arquitectura](https://github.com/certidevs/g2_aspnet/wiki/Arquitectura).
5. Cerrar con el trabajo pendiente y los siguientes pasos.

La aplicación sigue en desarrollo como proyecto del curso.
