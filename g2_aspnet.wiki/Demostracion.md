# Demostración

Con la carga inicial activada se crean los roles y estas cuentas:

| Usuario | Rol |
| --- | --- |
| `admin` | `Admin` |
| `user` | `Teacher` |
| `teacher` | `Teacher` |
| `student` | `Student` |
| `student2` | `Student` |
| `student3` | `Student` |

Las contraseñas de demostración están en el [README del repositorio](https://github.com/certidevs/g2_aspnet#primer-arranque). Las usamos para las prácticas; no son cuentas para publicar la aplicación con datos reales.

También se cargan centros, aulas, cursos, lecciones, matrículas, calificaciones y asistencias.

### Recorrido de demostración

1. Acceder al listado de centros y filtrar por ciudad.
2. Abrir un curso y consultar su centro y profesor.
3. Consultar las aulas y las lecciones disponibles.
4. Iniciar sesión como alumno y revisar sus matrículas y notas.
5. Iniciar sesión como profesor y consultar las calificaciones.
6. Iniciar sesión como administrador y abrir la gestión de usuarios.
7. Revisar el listado de asistencias y su búsqueda por lección, curso o alumno.

Consulta [Primeros pasos](https://github.com/certidevs/g2_aspnet/wiki/Primeros-pasos) para arrancar el proyecto y la [guía funcional](https://github.com/certidevs/g2_aspnet/wiki/Guia-funcional) para ver qué puede hacer cada perfil.
